## 结果解释边界

正文收益来自正式G4的10,000张官方测试图、三个配对seed，均使用原封存模型；作者自测的40张内部开发图仅验证工程复现。混合组保持真实样本数量，但改变真实损失系数，比较的是固定混合策略。零样本CLIP采用不同模型，作为产品决策中的替代参考。48.14分钟为选定阶段之和，排除环境、开发、人工和传输。

两份标注的类别可辨不等于整体图像质量合格。当前只有作者自测，外部用户易用性尚未验证。B原CPU/GPU严格数值差异仍保留为限制。未利用正式测试结果更改配置、选图、重训或重新评估。

## 编辑和重建

可直接在PowerPoint编辑PPTX并导出PDF；数值修改前应核对对应原始表。源码为[deck_content.mjs](deck_content.mjs)，固定数据快照为[presentation_data.json](presentation_data.json)，数据源哈希保存在快照中。现有PPTX含2个可编辑图表、6个可编辑表格及每页讲者备注。

[build_deck.mjs](build_deck.mjs)使用Codex捆绑的`@oai/artifact-tool`及原技能包校验器，不需要项目GPU环境。重建需要传入运行时Node模块目录、Python、演示技能目录和新的输出文件名；图片从已恢复的G3产物中读取并校验。临时文件集中在`runs/_cache/presentation_build/`，不进入Git；不覆盖既有输出。PDF由本机PowerPoint实际打开PPTX后导出，最终版本另核验了文本、数字与全部页面。
